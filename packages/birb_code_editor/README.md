# Birb code editor qualification

This package is an incomplete W1 engine experiment, not a usable editor release.
No public product API is exported. The existing `birb_design_system` editor is
unchanged.

Run `flutter test` from this directory. The mixed-separator fidelity test
currently fails intentionally against the unpatched candidate; do not skip it
or interpret the other passing probes as qualification.

See [engine evidence](../../docs/editor-engine-qualification.md) for the failure,
dependency provenance and the decision required before product implementation.
